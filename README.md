# MCQ Practice App

A Streamlit app for practicing multiple-choice questions with AI-powered explanations.

## Features
- Practice MCQs from predefined questions
- AI tutor for explanations (optional)
- Paginated view (1-15 questions per page)
- Score tracking
- 170+ Operating Systems questions included

## Files
- `app_predefined.py` - Main app for predefined questions
- `os_questions.json` - 170 OS Unit 4 questions
- `requirements.txt` - Dependencies

## Run Locally
```bash
streamlit run app_predefined.py
```

## Deploy to Streamlit Cloud
1. Push this repo to GitHub
2. Go to https://share.streamlit.io
3. Connect your GitHub repo
4. Select `app_predefined.py`
5. Deploy!

Your friends can then access via the Streamlit Cloud URL.
